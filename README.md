# Awesome Barter [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

A curated list of open-source tools, apps, protocols, and field manuals for barter economics and mutual aid.

> Please read the [contribution guidelines](CONTRIBUTING.md) before submitting a Pull Request.

## Contents
- [Valuation & Parity Engines](#valuation--parity-engines)
- [Apps & Local Exchange Platforms](#apps--local-exchange-platforms)

## Valuation & Parity Engines
* [BarterScore Engine](https://github.com/barterscoreengine/barterscore) - Zero-dependency, local-first JavaScript library that calculates exact barter parity for survival goods and essential human services in crisis scenarios, with a printable field manual.

## Apps & Local Exchange Platforms
* [Hylo](https://github.com/Hylozoic/hylo) - Commons-owned platform for groups that want to build trust, coordinate action, and grow together.
* [Karrot](https://codeberg.org/karrot) - Free and open-source tool for grassroots initiatives and groups of people that want to coordinate face-to-face activities on a local, autonomous and voluntary basis.

## Protocols & Field Manuals
* [Firmware for Meshtastic](https://github.com/meshtastic/firmware) - Open-source, off-grid mesh communication system.
* [Internet-in-a-Box (IIAB)](https://github.com/iiab/iiab) - Learning hotspot to those without Internet.
* [Kiwix JS](https://github.com/kiwix/kiwix-js) - Gateway for offline access to vast web resources.
